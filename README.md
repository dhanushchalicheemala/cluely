# Cluely Resume

This repository contains my interactive HTML resume designed for Cluely. The resume showcases my skills as an AI Engineer and Content Creator with a focus on creating viral content and AI solutions.

## Features

- Modern, responsive design using Tailwind CSS
- Interactive elements with hover effects
- Skill visualization with progress bars
- Timeline-based experience and education sections
- AI-themed styling and content

## View Resume

You can view the resume by opening the `resume.html` file in your browser or by visiting the GitHub Pages site for this repository.
